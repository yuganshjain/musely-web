Support

My computer doesn't show Musely in its Bluetooth list

Make sure Bluetooth is on and the computer isn't still bonded to a previous pairing. In the app, go to Settings → Pairing problems, which walks you through forgetting the old pairing on both sides and reconnecting.

The computer pairs but nothing moves

Some Bluetooth adapters accept the connection but delay the first input report. Open Settings → Pairing problems → Restart advertising, then try again. If it keeps happening on the same computer, it's usually a driver issue on that machine, not your phone.

Wrong characters appear when I type

Musely sends raw key presses, so the keyboard layout set in the app (Settings → Keyboard layout) must match what the computer expects. Switch it to match and reconnect.
